## 历史方法

前身区域 Earth Engine 方法完成过 2003—2010 年获取，覆盖 96 个月、70,128 个 UTC 小时、9 个变量及 37 × 61 格点。历史原始文件后来已删除，本仓库不包含这些数据，也未恢复原文件。

历史成果仅作为方法背景。新 SDK 客户端的真实服务响应和认证行为尚未重新进行在线验收。历史 CDS、ARCO 小样本不证明多年性能、当前服务权限、生产适配器可用性或不同渠道逐值相同。

## 离线验证

测试使用临时目录中的合成数组，覆盖 UTC 边界与连续性、原生网格坐标、响应类型与形状、有限值、输出校验、续跑配置变化、路径限制、归档防覆盖、临时错误重试及 ZIP CRC。

```sh
python -m unittest discover -s tests
```

Windows / Python 3.12 的本地验证：18 项离线测试通过；隔离环境中的 wheel 构建与安装、CLI 规划/核验/打包及合成单点 Parquet/DuckDB 查询示例通过。详见[机器可读核验快照](validation.json)。该快照记录准备源码时的状态，发布和 CI 的最新状态以 GitHub 仓库为准。

GitHub Actions 配置为 Python 3.11、3.12 离线测试，无需云端密钥。本地测试不能证明上游当前可用性、配额、相对于独立基准的地理精度或特定研究的科学有效性。本轮没有下载新气象数据、接入私人数据库或启用定时任务。
